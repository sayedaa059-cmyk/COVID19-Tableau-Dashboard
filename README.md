# 🦠 COVID-19 Global Dashboard | Tableau Capstone Project

## 📌 Project Overview
An interactive Tableau dashboard analyzing global COVID-19 data 
from 2020 to 2026, including case trends, mortality rates, 
country comparisons, vaccination impact, and future projections.

**Batch:** DABATCH17WKDY25  
**Tool:** Tableau Desktop + Microsoft Excel  
**Module:** Data Visualization using Tableau  

---

## 🎯 Key Features

### 5 Interactive Charts
| Chart | Type | Description |
|-------|------|-------------|
| Monthly New Cases | Bar Chart | 2020–2024 pandemic trend |
| Case Fatality Rate | Line Chart | CFR decline from 5% to 1% |
| Country Comparison | Horizontal Bar | 25 countries ranked by cases |
| Projections 2025–26 | Grouped Bar | 3 scenario forecasts |
| Vaccination vs Deaths | Bubble Scatter | Region-colored correlation |

- 🔵 **Total Cases:** 176M

- 🟢 **Total Recovered:** 161M

---

## 💡 Key Insights

1. **Omicron Peak** — Cases peaked at ~10M/month in December 2021,
   the highest point of the entire pandemic

2. **Vaccine Impact** — CFR dropped 80% from 5.0% (2020) to 1.0% 
   (2024), directly correlating with mass vaccination rollout

3. **Vaccination vs Mortality** — Countries with 75%+ vaccination 
   rates show significantly fewer deaths per million population

4. **Endemic Transition** — By 2024, monthly cases declined 96% 
   from the 2021 peak

5. **Africa Underreporting** — Nigeria (219M population) reported 
   only 267K cases, suggesting massive testing gaps
